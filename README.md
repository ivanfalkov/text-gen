# Dialog Summarization - генерация текста
## 1. О задаче.
    В этой работе решается задача абстрактивной суммаризации диалогов на датасете [DialogSum](https://www.kaggle.com/datasets/marawanxmamdouh/dialogsum/data) (~13k диалогов с референсными краткими саммари, сплиты train/val/test, формат JSONL с полями `dialogue` и `summary`): цель — показать полный цикл работы с генеративной LLM под конкретную задачу и измерить, насколько LoRA-дообучение улучшает качество относительно бейзлайнов, для чего последовательно строятся бейзлайн без ML (эвристика «первое + последнее предложение»), бейзлайн LLM без дообучения (небольшая decoder-only модель <1B через `vLLM`), LoRA-дообучение той же модели (через `trl`/`unsloth` с трекингом в ClearML) и оценка через LLM-as-judge на бесплатном API Groq; качество измеряется метриками ROUGE-1/2/L и BLEU, а также ручным просмотром примеров, при этом работа ведётся локально на GPU NVIDIA RTX 4060 Laptop (8 GB VRAM), что накладывает ограничения на размер модели и требует квантизации при обучении.
